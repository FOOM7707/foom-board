# 품(FOOM) 개발 현황판

팀이 진행 상황을 한 화면에서 보는 페이지입니다. **서비스 코드가 아닙니다** — 품 서비스와는 별개이고, 이 저장소에는 현황판 파일 하나만 들어 있습니다.

## 주소

**https://foom7707.github.io/foom-board/**

링크만 누르면 열립니다. 설치할 것도, 로그인도 필요 없습니다(휴대폰도 됩니다).

## 무엇이 보이나

- **요약 4칸** — 전체 진행률 / 현재 단계 / 개발 기간 / 자동 점검 수
- **전체 일정** — 9단계를 8~12월 축에 막대로. 채워진 부분이 완료된 만큼이고, 오늘 위치가 세로선으로 표시됩니다. 막대를 누르면 그 단계 항목이 열립니다
- **단계별 작업** — 항목마다 **완료 / 진행 중 / 막힘 / 미착수** 상태와 **왜 그 상태인지** 한 줄
- **바뀐 기록** — 어떤 항목의 상태가 언제 바뀌었는지 최근 12건
- **외부에서 풀어야 하는 것** — 계약·심사처럼 개발로는 해결되지 않는 항목
- **작업량 추이** — 날짜별 변경 묶음 수

찾기(검색), 상태·영역별로 걸러 보기, 모두 펼치기·접기, 화면 밝기 바꾸기가 됩니다. 인쇄하면 A4에 맞게 나옵니다.

## 이 주소는 보기 전용입니다

위의 기능은 전부 되지만, **항목 상태를 눌러 바꾸는 것만 되지 않습니다.** 화면 위에 그 이유가 안내로 뜹니다(고장이 아닙니다).

## 내용을 고치려면

`index.html` 안의 `<script id="state">` **한 곳**에 모든 값이 모여 있습니다. 그 부분만 고쳐서 올리면 진행률·일정 막대·요약 숫자가 전부 따라 바뀝니다. 올린 뒤 1분쯤 지나면 화면에 반영됩니다.

| 무엇이 바뀌었나 | 어디를 고치나 |
|---|---|
| 항목을 끝냈다 / 시작했다 / 막혔다 | 그 항목의 `status` — `done`(완료) `wip`(진행 중) `blocked`(막힘) `todo`(미착수) |
| 왜 그 상태인지 설명이 필요하다 | 같은 항목의 `why` — 한 줄. 비워두면 상태만 보이고 이유가 안 보입니다 |
| 계약·심사처럼 개발로 안 풀리는 것이 생겼다 | `external` |
| 커밋 수·점검 종수가 늘었다 | `totals` |
| (매번) | `updated`를 **오늘 날짜로**. 안 바꾸면 팀이 옛 화면을 보고 최신인 줄 압니다 |

`rev`(판 번호)와 `log`(바뀐 기록)는 손대지 않습니다.

> 품 프로젝트 쪽에서는 이 갱신이 **작업 마무리 절차에 들어가 있습니다** — 프로젝트의 `CLAUDE.md` 「작업이 끝나면 현황판도 갱신합니다」 참고.

## 진행률은 어떻게 계산하나

계획 항목 수를 기준으로 **완료 1점, 진행 중 0.5점, 미착수·막힘 0점**입니다. **작업량이나 난이도를 반영한 값이 아닙니다** — 「공정률 37%」처럼 읽지 마세요.

## 검색에는 걸리지 않습니다

`noindex` 설정과 `robots.txt`로 검색엔진 수집을 막아 뒀습니다. 다만 **주소를 아는 사람은 누구나 열 수 있습니다** — 비밀번호는 걸 수 없습니다.
