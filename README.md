# 품(FOOM) 개발 현황판

팀이 진행 상황을 한 화면에서 보는 페이지입니다. **서비스 코드가 아닙니다** —
품 서비스와는 별개이고, 이 저장소에는 현황판 파일 하나만 들어 있습니다.

## 주소

저장소 설정의 **Pages** 항목에 표시되는 주소로 열립니다. 링크만 있으면
설치할 것 없이 브라우저에서 바로 열립니다(휴대폰도 됩니다).

## 이 주소는 보기 전용입니다

찾기 · 상태와 영역별로 걸러 보기 · 펼치기와 접기 · 화면 밝기 · 인쇄는 전부 됩니다.
**항목 상태를 눌러 바꾸는 것만 되지 않습니다.**

## 내용을 고치려면

`index.html` 안의 `<script id="state">` 한 곳에 모든 값이 모여 있습니다.
그 부분만 고쳐서 올리면 진행률 · 일정 막대 · 요약 숫자가 모두 따라 바뀝니다.
올린 뒤 1분쯤 지나면 화면에 반영됩니다.

## 검색에는 걸리지 않습니다

`noindex` 설정과 `robots.txt`로 검색엔진 수집을 막아 뒀습니다.
다만 **주소를 아는 사람은 누구나 열 수 있습니다** — 비밀번호는 걸 수 없습니다.
